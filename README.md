# long-d-helper — 3D 캐릭터 커스터마이저

Three.js(React Three Fiber)로 만든 브라우저용 3D 캐릭터 뷰어입니다. 마우스로 회전/확대하며 캐릭터의 피부색, 옷 색상, 애니메이션(대기/손흔들기/걷기)을 실시간으로 바꿔볼 수 있습니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173`을 열면 됩니다.

## 프로젝트 구조

- `src/Character.tsx` — 프로시저럴(구/캡슐 도형 조립) 3D 캐릭터와 애니메이션 로직
- `src/App.tsx` — 3D 씬 구성(조명, 카메라, 컨트롤) 및 커스터마이징 UI 패널
